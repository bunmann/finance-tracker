HTTP METHODS (CRUD):
    GET    -> Read data
    POST   -> Create data
    PUT    -> Update data
    DELETE -> Delete data

FASTAPI BASIC ROUTE:
    from fastapi import FastAPI
    app = FastAPI()
    
    @app.get("/")
    def read_root():
        return {"hello": "world"}

RUNNING UVICORN:
    uvicorn main:app --reload

PATH VS QUERY PARAMETERS:
    Path Parameter: part of the URL path itself
    e.g. @app.get("/items/{item_id}")
    
    Query Parameter: key-value pairs appended after '?' in the URL
    e.g. @app.get("/items/")  -> /items/?skip=0&limit=10
