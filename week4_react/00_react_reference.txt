LESSON 1: Web Foundations (HTML, CSS, JS)

    Frontend has: HTML (content), CSS (styling), JS (logic)
        -> JS is client-side - runs on user's browser
        -> FastAPI is server-side - runs on server, sends HTML to browser
        
        
    1. HTML (HyperText Markup Language): uses tags to define elements (has opening & closing tags)
    e.g. <h1>This is a heading</h1>
    -> / is the closing tag that tells the element ends there

    Common tags: can be nested into parent & children elements
    | Tag | What it creates | Example |
    |---|---|---|
    | `<h1>` to `<h6>` | Headings (h1 is biggest, h6 is smallest) | `<h1>Finance Tracker</h1>` |
    | `<p>` | A paragraph of text | `<p>Welcome to my app.</p>` |
    | `<div>` | A generic container/box (used to group elements) | `<div> ... stuff inside ... </div>` |
    | `<button>` | A clickable button | `<button>Submit</button>` |
    | `<input>` | A text input field (like a form box) | `<input type="text" />` |
    | `<img>` | An image | `<img src="photo.jpg" />` |
    | `<table>`, `<tr>`, `<td>` | A table, table row, table cell | See below |
    | `<ul>`, `<li>` | An unordered (bullet) list and list items | `<ul><li>Item 1</li></ul>` |
    | `<a>` | A hyperlink | `<a href="https://google.com">Google</a>` |

    Attributes (extra info on tags, like function parameters): provide configuration for the element
    e.g. `src`, `width`, `href`, `type`, `placeholder` are all attributes

    Self-closing tags: no separate closing tag needed
    e.g. <img src="photo.jpg" /> 
         <input type="text" />        
         <br />                        
    -> / at the end says this tag opens & closes itself


    2. CSS (Cascading Style Sheets): controls how HTML elements look (colors, sizes, fonts, spacing, layout, etc)
    -> Write in seperate .css file & import it in JS
    
    Write rules that target HTML elements:
    e.g. h1 { // Makes all h1 large and blue
        color: blue;
        font-size: 32px;
        } 

    CSS Selector: targets specific HTML elements using selectors (assinging class and using . is MOST COMMON)
    
    | Selector | What it targets | Example |
    |---|---|---|
    | `h1` | All `<h1>` elements | `h1 { color: red; }` |
    | `.card` | All elements with `class="card"` | `.card { background: white; }` |
    | `#header` | The single element with `id="header"` | `#header { height: 60px; }` |

    Common CSS Properties:
    | Property | What it does | Example |
    |---|---|---|
    | `color` | Text color | `color: white;` |
    | `background-color` | Background color | `background-color: #1a1a2e;` |
    | `font-size` | Text size | `font-size: 18px;` |
    | `padding` | Space **inside** the element (between content and border) | `padding: 10px;` |
    | `margin` | Space **outside** the element (between it and neighbors) | `margin: 20px;` |
    | `border` | Border around the element | `border: 1px solid gray;` |
    | `border-radius` | Rounded corners | `border-radius: 8px;` |
    | `width` / `height` | Size of the element | `width: 300px;` |
    | `display: flex` | Arrange children in a row or column | `display: flex;` |
    | `text-align` | Align text left/center/right | `text-align: center;` |
    

    3. JS Basics: Key differences from Python

    Variables: 
    const var1 = value; // not resasignable
    let var2 = value; // reassignable
    ** Use const by default 

    Functions: First class citizens, can be treated as variables, PASS BY SHARING
    Normal function:
    function add(a, b) {
    return a + b;
    }

    Arrow function (more common in React): like lambda, add is variable
    const add = (a, b) => {
    return a + b;
    };

    Shorter arrow function (implicit return):
    const add = (a, b) => a + b;
    
    String interpolation (f-string):
    -> replace " w/ ` &  {} w/ ${}
    e.g. `Hello ${name}, you are ${age} years old`

    Arrays (Python Lists)
    Python: numbers = [1, 2, 3]
    const numbers = [1, 2, 3];

    Python: numbers.append(4)
    numbers.push(4);

    Python: [x * 2 for x in numbers]   (list comprehension)
    numbers.map(x => x * 2);               // [2, 4, 6]  — .map() is the JS equivalent

    Python: [x for x in numbers if x > 2]   (filtered list comprehension)
    numbers.filter(x => x > 2);             // [3]

    ** .map is EXTREMELY important in React for rendering lists **

    Objects (Python Dicts):
    // Python:  person = {"name": "David", "age": 20}
    const person = { name: "David", age: 20 };  // no quotes needed on keys

    // Python:  person["name"]
    person.name;    // dot notation (more common in JS)

    // Destructuring — pull values out of an object into variables:
    const { name, age } = person;
    // Now name = "David" and age = 20
    // This is like Python's: name, age = person["name"], person["age"]

    Console Logging (Print):
    e.g. console.log("hello");

    Ternary Operator `? :` (Inline If/Else):
    e.g. const status = age >= 18 ? "adult" : "minor";

    Spread operator ... (like * or ** unpacking):
    For lists: const oldList = [1, 2, 3];
               const newList = [...oldList, 4];    // [1, 2, 3, 4], Python: new_list = [*old_list, new_item]

    For dicts: const oldObj = { name: "David", age: 20 };
               const newObj = { ...oldObj, age: 21 };   // { name: "David", age: 21 }, Python: new_dict = {**old_dict, "age": 21}

    Async/Await for API response:
    const fetchData = async () => {
        const response = await api.get('/transactions');  // waits for response
        console.log(response.data);                       // runs after response arrives
    };

    == vs ===: 
    -> == changes types before comparing (e.g. 5 is same as "5")
    -> === is STRICT equals (e.g. they arent the same)
    ** ALWAYS USE === **

    Exporting and Importing:
    -> export const add = (a, b) => a + b;
    -> import { add, subtract } from './math';


LESSON 2: React Basics

    React: Biggest JS library used to make UI in components 
    -> Syntax: JSX: JS XML, like HTML

    React Component (Building block): JS function that returns JSX 
    -> can be nested in each other to pass props

    Key JSX rules:
        | Rule | Example |
        |------|---------|
        | Must return **one** parent element | Wrap everything in a `<div>` or `<>...</>` (fragment) |
        | Use `className` instead of `class` | `<div className="box">` (because `class` is reserved in JS) |
        | Use `{}` to embed JavaScript expressions | `<p>Total: {2 + 2}</p>` renders as "Total: 4" | ** IMPORTANT FOR PASSING FUNCTIONS
        | Self-closing tags need `/` | `<img src="..." />` not `<img src="...">` |

    Props (properties): like parameters, Read-only, flows DOWN from parent to children

    State (Dynamic component): data that can change over time inside a component, auto re-renders
    -> import { useState } from 'react';
    e.g. const [count, setCount] = useState(0);
    -> current value, setter function, initial value
    -> call setter function w/ setCount(newCount);, executes entire parent function again

    * Pure vs Side Effect Functions: 
    -> Pure: Same input always = same output, no side effects, doesnt interact w/ outside world
    -> Side Effect: Output depends on external factors (API, time, etc), modifies state/DOM/etc
    ** useEffect only used for side effects **

    useEffect (Side effects): used for fetching data from APIs, setting timers, updating titles
    -> import { useEffect } from 'react';
    -> useEffect accepts two arguments: a function and a dependency array
    -> The function runs after the component renders
    -> The dependency array controls when the function runs (empty array = once on mount (added to screen), [var] = when var changes, nothing = after every re-rendeer (usually bad))
    
    e.g. useEffect(() => {  
        console.log("Component mounted");
    }, []);

    | Concept | C++ Equivalent | Python/FastAPI Equivalent | React |
    |---|---|---|---|
    | Code organization | Classes | Modules/Routes | **Components** |
    | Passing data | Constructor params | Function params | **Props** |
    | Mutable data | Member variables | Instance variables | **State (`useState`)** |
    | Initialization | Constructor | `__init__` | **`useEffect(() => {}, [])`** |
    | Rendering | `cout <<` / `print()` | `return {...}` in endpoint | **`return <JSX />`** |
